# hive_trust.aleo — ZK Wallet Reputation on Aleo

Zero-knowledge proof system for Hive Civilization wallet reputation. Proves cryptographic wallet control, activity thresholds, and trust tiers **without revealing balances, transaction counts, or counterparties**.

## Architecture

```
Phase 1 (Live):  EIP-712 signed attestation from Base L2 wallet
Phase 2 (Q2 2026): Native Aleo Leo program — ZK proofs on mainnet
Phase 3 (Future):  Trustless Base→Aleo bridge via RISC Zero Steel
```

### How it works

1. **Wallet owner** signs an EIP-712 structured attestation from `0x15184bf50b3d3f52b60434f8942b7d52f2eb436e` on Base L2
2. **Aleo program** takes attestation data as private inputs, asserts conditions (e.g., activity >= threshold), and produces a public proof
3. **Enterprise evaluators** verify the on-chain proof — they see "proven" but never see the underlying data

### What gets proven publicly
- Wallet address control (ECDSA signature)
- Activity meets claimed threshold (ZK assertion)
- Trust tier meets minimum requirement (ZK assertion)

### What stays hidden
- Actual USDC balance
- Transaction amounts and counterparties
- Raw activity scores

## Program Transitions

| Transition | Purpose | Private Inputs | Public Outputs |
|-----------|---------|---------------|----------------|
| `issue_credential` | Issue a HiveTrust credential | wallet hash, activity score, trust level | minimum threshold, claimed tier |
| `verify_reputation` | Prove credential meets tier | TrustCredential record | required tier, boolean result |
| `prove_activity` | Prove activity exceeds threshold | tx count, volume | min thresholds, boolean result |

## Deployment

```bash
# Install Leo
curl -L https://raw.githubusercontent.com/ProvableHQ/leo/main/install.sh | sh

# Build
leo new hive_trust
# Copy hive_trust.aleo to src/main.leo
leo build

# Deploy to Aleo mainnet (requires ALEO tokens)
leo deploy --network mainnet

# Execute prove_activity with private inputs
leo execute prove_activity \
    --network mainnet \
    --private-key $ALEO_PRIVATE_KEY \
    -- \
    1247u64 \        # private: actual tx count (hidden)
    89430000u64 \    # private: actual volume in cents (hidden)
    1u64 \           # public: minimum tx threshold claimed
    1u64             # public: minimum volume threshold claimed
```

The proof confirms: "this wallet has processed >= 1 transaction and >= $0.01 volume" without revealing the actual 1,247 transactions or $894K volume.

## Proof Generation

ZK proofs are generated by **Nordic Mine's 115 Aleo PoSW miners**. Aleo's Proof-of-Succinct-Work mechanism means the same hardware mining ALEO tokens also accelerates zkSNARK proof generation for HiveTrust credentials.

## Trust Model

- **Phase 1**: Wallet owner provides honest attestation data. EIP-712 signature proves wallet control. No ZK computation required.
- **Phase 2**: Aleo ZK proves the math. The attestation source data integrity relies on the wallet owner (or a signed third-party attestation).
- **Phase 3**: Fully trustless — RISC Zero Steel reads Base L2 state directly, no honest attestation required.

## Verification Endpoint

```
GET https://hivetrust.onrender.com/v1/trust/wallet-attestation
```

Returns the Phase 1 attestation data including wallet address, EIP-712 schema, and ZK proof status.
